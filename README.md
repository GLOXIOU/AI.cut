# AI.cut
A video editing software powered entirely by AI, featuring capabilities such as motion design and much more.

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/GLOXIOU/AI.cut

# Go to the project directory
cd AI.cut

# Install dependencies
npm install

# Start the server
npm start

# Then the app will start

```

Or you can use the [release version](https://github.com/GLOXIOU/AI.cut/releases) on github.
---

## 🧩 Usage

1. On the homepage, create a **new project** (you can create multiple for different projects).  
2. Select your file, import them on the logiciel.  
3. You can do the editing by yourself, or connect an AI via MCP server (Settings → Connect an AI, on the top right of the software).  
4. When you are finished, ask your AI to export the final video or do it yourself.

> New to AI.cut? Click **Take the tour** on the homepage for a quick guided tour.  
> You can also change the language, import your motion design, sound or meme...

## ✨ Features

**Interface**
- Fully customizable layout: drag tabs to group, stack or dock panels anywhere, resize, minimize or close them, re-add them from the Panels menu
- Workspaces are complete layouts: 6 built-in ones (Editing, Text, Effects, Captions, Audio, Auto) that you can rename, duplicate, reset or delete, plus your own
- Dedicated tool panels for the selected clip: tracking, blur, mask, color, cutout, video tools, animation, audio effects
- Separate AI panel (chat, ideas, style), folded until you need it
- Settings with tabs: general, connect an AI, background jobs and a detailed AI activity log (every tool call, its arguments, duration and errors)
- Program monitor on a second screen
- Quick guided tour, French / English interface

**Editing**
- Multi-track timeline (video, audio, subtitles), split, ripple delete, trim, snapping, markers, in / out points
- Premiere-style shortcuts (J K L, I / O, Ctrl+K, Q / W, Ctrl+Shift+E to export a frame…), all remappable in Settings → Keyboard shortcuts
- Transitions, keyframes, entrance / exit / loop animations, rounded cards, borders, shadows, layouts (PIP, split screen, blur fill)
- Text-based editing from the transcript, silence and filler-word removal, auto zooms, freeze frames, beat markers
- Auto reframe for vertical / square formats, reverse, stabilize, smooth slow motion

**Effects & color**
- Adjustment layers: blur, pixelate and grade everything below, on the whole frame or inside a mask (rectangle / ellipse, feathered, inverted)
- One-click blur: whole frame, an area, censor an area (pixels), blurred edges
- Lumetri-like color grading (exposure, temperature, highlights, shadows, split toning…) and 16 ready-made looks
- Chroma key, vignette, motion design templates (HTML / CSS / Lottie), animated subtitles with smart keywords

**Tracking & cutout**
- Object and face tracking, with manual correction
- Attach anything to a tracked object: text with a pointer, image, sticker, video…
- Blur / pixelate / spotlight that follows a face or an object
- Cut out a person or an object to put text or a photo behind them

**Audio**
- 24 audio effects and 21 presets (reverb, walkie-talkie, phone, robot, pitch, echo, 8D, lo-fi…) on clips or whole tracks
- Track mixer (volume, pan, mute / solo), music ducking, voice leveling, loudness normalization
- Voice / music separation
- Built-in sound effects, music without credit, real internet memes, YouTube download

**AI**
- Any AI can edit through the MCP server (Claude Code, Codex, Cursor, Gemini…) or the built-in chat
- "Ask the AI here": the Ask button above the playhead, the bubble that appears when the mouse rests on the timeline, or a right-click — the instruction is pinned at that precise spot
- AI ideas shown as ★ Idea flags right on the timeline: preview, compare with / without, keep or reject
- The AI saves checkpoints of the whole edit before big changes
- Copy the editing style of a video from its link (pacing, captions, look, sound)
- Automatic transcription, media analysis and AI visual notes

**Export**
- MP4, MOV, WebM, GIF, audio only, presets for YouTube / TikTok / Instagram, GPU encoding, subtitle files
