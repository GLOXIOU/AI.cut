# AI.cut
A video editing software powered entirely by AI, featuring capabilities such as motion design and much more.

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/GLOXIOU/AI.cut

# Go to the project directory
cd AI.cut

# Install dependencies
npm install

# Start the server
npm start

# Then the app will start

```

Or you can use the [release version]() on github.
---

## 🧩 Usage

1. On the homepage, create a **new project** (you can create multiple for different projects).  
2. Select your file, import them on the logiciel.  
3. You can do the editing by yourself, or connect an AI via MCP server (on the top right of the software).  
4. When you are finished, ask your AI to export the final video or do it yourself.

> You can also change the language, import your motion design, sound or meme...
